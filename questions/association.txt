PROBLEM 1
---------
A doctor sees many patients and a patient sees many doctors. Neither owns the
other and neither controls the other's lifetime. Implement this many-to-many
association so that `Doctor.add_patient()` keeps BOTH sides in sync, and calling
it twice with the same patient does not create a duplicate.
Note: the classic bug here is updating one side and forgetting the other. Make
`doctor.patients` and `patient.doctors` impossible to disagree.
Evaluate the time and space complexity of `add_patient()`. Define your variables
and provide a rationale for why you believe your solution has the stated time
and space complexity.

```
class Doctor:
    def __init__(self, name):
        self.name = name
        self.patients = []

    def add_patient(self, patient):
        pass

class Patient:
    def __init__(self, name):
        self.name = name
        self.doctors = []
```

Example Usage:

```
d = Doctor("Dr. Reyes")
p = Patient("Ana")
d.add_patient(p)
d.add_patient(p)
print([x.name for x in d.patients])
print([x.name for x in p.doctors])
```

Example Output:

```
['Ana']
['Dr. Reyes']
```
